# Inventaire des visuels WACDO

## Sources disponibles

- `dictionnaire.csv` : dictionnaire de donnees
- `mcd.mmd` : modele conceptuel de donnees
- `mld.md` : explication du modele logique
- `mld.mmd` : schema relationnel du modele logique
- `mpd.sql` : modele physique et script SQL
- `classes-metier.mmd` : diagramme de classes metier
- `classes-application.mmd` : diagramme de classes application
- `classes-source.excalidraw` : source editable du diagramme de classes
- `architecture.mmd` : schema d'architecture
- `parcours-commande.mmd` : parcours et cycle de vie d'une commande
- `benchmark-choix-techniques.md` : comparatifs PHP, bases de donnees, front,
	Docker et reverse proxy
- `chronologie-et-vocabulaire-wacdo.md` : ordre de construction, dates Git et
	glossaire technique et metier

## Captures manquantes

- borne : a capturer depuis la page de borne
